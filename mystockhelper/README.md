# MyStockHelper — Zero-Cost Telegram Stock Monitor

Priority watchlist: PCLA, NVDA, ORCL, ESTC, XOS.

Telegram commands: `/start`, `/help`, `/chatid`, `/watchlist`, `/status`, `/stock NVDA`.

Required environment variables: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_CHAT_ID`, `MONITOR_SECRET`. Optional: `SEC_USER_AGENT`.

The default Yahoo chart source is unofficial/best-effort and is not treated as exchange-grade real-time data. Do not use the alert alone for immediate trade execution.
